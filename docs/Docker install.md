# Как установить Docker Desktop на Windows 10 или 11

Эта инструкция поможет скачать Docker Desktop с официального сайта, установить его и запустить первый тестовый контейнер. Опыт работы с Docker и Linux не нужен. Docker Desktop — приложение, которое запускает контейнеры на вашем компьютере. Мы настроим его для Linux-контейнеров через WSL 2 — подсистему Linux в Windows.

## 1. Проверьте компьютер

1. Нажмите `Win + R`, введите `winver` и нажмите Enter. Запишите версию и номер сборки Windows.
2. Откройте **Параметры → Система → О системе**. Найдите «Тип системы»: процессор **x64** (обычно Intel или AMD) или **ARM64**. Там же проверьте, что установлено не менее **8 ГБ оперативной памяти**.
3. Нажмите `Ctrl + Shift + Esc`, чтобы открыть Диспетчер задач. На вкладке **Производительность → ЦП** проверьте, что строка «Виртуализация» показывает «Включено». Если она выключена, найдите инструкцию производителя по включению виртуализации в BIOS/UEFI. На рабочем компьютере обратитесь в ИТ-поддержку.
4. Сверьте версию, редакцию и архитектуру Windows с [системными требованиями Docker Desktop](https://docs.docker.com/desktop/setup/install/windows-install/). Для Windows 10 в требованиях указана версия **22H2 (сборка 19045)**, но номер сборки сам по себе не гарантирует поддержку: Docker учитывает срок обслуживания выпуска Windows. Для новой установки предпочтительнее актуальный поддерживаемый выпуск Windows 11.

## 2. Установите или обновите WSL

1. Откройте меню **Пуск**, введите `PowerShell`, нажмите правой кнопкой по **Windows PowerShell** и выберите **Запуск от имени администратора**. Если Windows спросит разрешение, нажмите **Да**.
2. Введите команду и нажмите Enter:

   ```powershell
   wsl --version
   ```

3. Если команда выводит версию WSL, переходите к обновлению ниже. Если WSL ещё не установлен или команда не показывает версию, выполните:

   ```powershell
   wsl --install --no-distribution
   ```

   Перезагрузите компьютер, если Windows этого попросит. Для Docker Desktop не нужно отдельно устанавливать Ubuntu: флаг `--no-distribution` пропускает этот шаг.

4. Снова откройте PowerShell от имени администратора и выполните команды по очереди:

   ```powershell
   wsl --update
   wsl --version
   ```

   В выводе первая строка с версией **WSL** должна показывать **2.1.5 или новее**. Не путайте её со строкой «Версия ядра».

## 3. Скачайте и установите Docker Desktop

1. Откройте [официальную страницу загрузки Docker Desktop для Windows](https://docs.docker.com/desktop/setup/install/windows-install/).
2. Нажмите кнопку загрузки **Windows – x86_64**, если у вас процессор x64, или **Windows – Arm**, если у вас ARM64. На странице проверьте, что выбранный выпуск поддерживает вашу версию Windows.
3. Откройте папку **Загрузки** и дважды щёлкните по `Docker Desktop Installer.exe`.
4. Если установщик предложит **Use WSL 2 instead of Hyper-V**, оставьте этот пункт включённым. Продолжите установку и перезапустите компьютер или выйдите из системы, если установщик попросит.
5. Найдите **Docker Desktop** в меню **Пуск** и запустите его. Прочитайте условия использования и примите их, если согласны. Если приложение предлагает войти в аккаунт и показывает кнопку **Skip**, её можно нажать для локальной проверки.
6. Дождитесь запуска Docker Desktop. Если нужно проверить режим, откройте **Settings → General**: параметр **Use the WSL 2 based engine** должен быть включён. Если вы его изменили, нажмите **Apply**.

## 4. Запустите тестовый контейнер

Откройте новое окно PowerShell. Права администратора для этой проверки не нужны. Выполните команды по одной:

```powershell
docker --version
docker run --rm hello-world
```

Первая команда показывает версию программы `docker`. Вторая скачивает тестовый образ `hello-world`, если его ещё нет на компьютере, и запускает из него контейнер. При первом запуске нужен интернет. `--rm` удаляет тестовый контейнер после завершения, но оставляет скачанный образ.

Если появилось сообщение `Hello from Docker!`, установка прошла успешно. Контейнер завершится сам — так и задумано.

## Если что-то не получилось

| Что видите | Что сделать |
| --- | --- |
| `wsl --version` не работает или `wsl --install` выводит справку | Проверьте обновления Windows и откройте [инструкцию Microsoft по установке WSL](https://learn.microsoft.com/windows/wsl/install). |
| `wsl --update` не может загрузить обновление из Microsoft Store | В PowerShell от имени администратора попробуйте `wsl --update --web-download`. На управляемом компьютере при блокировке загрузки обратитесь в ИТ-поддержку. |
| `docker` не распознаётся как команда | Закройте PowerShell и откройте заново. Если ошибка остаётся, убедитесь, что установка Docker Desktop завершилась, и перезагрузите компьютер. |
| `docker --version` работает, но тест не подключается к Docker | Откройте Docker Desktop из меню «Пуск» и дождитесь запуска. Если приложение уже открыто, проверьте в **Settings → General**, что включён движок WSL 2. |
| Docker работает, но не скачивает `hello-world` | Проверьте интернет. Если вы в корпоративной сети, уточните у ИТ-поддержки, требуется ли прокси или разрешён ли доступ к Docker Hub. |

> Для рабочего компьютера: перед установкой проверьте [условия лицензирования Docker Desktop](https://docs.docker.com/subscription/desktop-license/) и правила вашей организации.
